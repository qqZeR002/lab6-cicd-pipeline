# Лекция 2. Юнит-тесты

Юнит-тест проверяет одну функцию отдельно от остальной программы.

## Структура теста

1. подготовить данные
2. вызвать функцию
3. сравнить результат с ожидаемым

## Пример на pytest

```python
def test_sum():
    assert sum([1, 2, 3]) == 6
```

## Покрытие

- показывает, какие строки кода выполнялись в тестах
- считается командой `pytest --cov`
- 100 % покрытия не значит, что ошибок нет
