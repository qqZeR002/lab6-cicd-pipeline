# Лекция 1. Основы Git

Git это система контроля версий. Она хранит историю изменений проекта.

## Основные команды

1. `git init` создаёт репозиторий
2. `git add` добавляет файлы в индекс
3. `git commit` сохраняет снимок

## Пример

```bash
git init
git add README.md
git commit -m "Первый коммит"
```

## Что запомнить

- коммит это снимок всего проекта
- ветка это указатель на коммит
- конфликт возникает, когда две ветки меняют одни и те же строки
